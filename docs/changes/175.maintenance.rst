This includes using ``instance = cls()`` instead of reassigning ``cls`` in the classmethods of :class:`~pyvisgen.dataset.SimulateDataSet` and :class:`~pyvisgen.io.DataConverter`, as well as replacing ``dict()`` calls and unnecessary list comprehensions with literals and generators.

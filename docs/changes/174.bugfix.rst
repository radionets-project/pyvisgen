Fixed the image grid: :attr:`~pyvisgen.simulation.Observation.lm` is now a uniform, square grid in the direction cosines (SIN projection) and :attr:`~pyvisgen.simulation.Observation.rd` is derived from it by inverting the projection, so pixels are square at any declination. :func:`~pyvisgen.simulation.angular_distance` now uses the great-circle separation to match the new ``rd`` convention.

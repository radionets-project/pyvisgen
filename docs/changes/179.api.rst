The default of ``normalize`` in :func:`~pyvisgen.simulation.vis_loop` and the ``sampling`` section of the configuration is now ``False``, which gives visibilities in the standard convention with ``V_11 = V_22 = I``. With ``normalize=True``, the visibilities, the noise and the weights are scaled consistently by a factor of 0.5, as before. The UVH5 and FITS writers and :func:`~pyvisgen.simulation.generate_noise` got the arguments ``normalize`` and ``scale``, respectively. The gridding of the visibilities requires a version of ``pyvisgrid`` that supports the argument ``normalized`` of ``Gridder.from_pyvisgen``.

Added optional per-antenna SEFD scaling to the noise simulation. The relative SEFD of each station can be set with the new ``ant_sefd_scale`` argument of :class:`~pyvisgen.simulation.Observation`, or read from the new ``[bands.<band>.ant_scale]`` table of the telescope noise config, and is applied in both noise modes of :func:`~pyvisgen.simulation.generate_noise`. The noise config of MeerKAT now contains fitted factors for the L-band, so noise and weights of MeerKAT simulations differ per baseline.
